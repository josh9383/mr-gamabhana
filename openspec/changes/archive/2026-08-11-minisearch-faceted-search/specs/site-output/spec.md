## MODIFIED Requirements

### Requirement: [REQ-SO-001: Home page]
The build SHALL generate `site/index.html` from `templates/index.html.j2`, rendering the site title, description, catalogue links (including a link to the search page), and placeholder containers for the client-side catalogue groups. Its canonical URL SHALL be the site root.

#### Scenario: Home page is generated
- **WHEN** the build completes
- **THEN** `site/index.html` exists, contains the site title and description, and declares a canonical URL pointing at the site root

#### Scenario: Home page links to the search page
- **WHEN** the home page is generated
- **THEN** its catalogue links include a link to `site/search.html`

### Requirement: [REQ-SO-006: Sitemap]
The build SHALL generate `site/sitemap.xml` listing the home URL, the search URL, the ideas landing URL, every idea page URL, every catalogue landing URL, and every individual catalogue page URL, each prefixed with the site's `base_url`.

#### Scenario: Sitemap covers generated pages
- **WHEN** the build completes
- **THEN** `site/sitemap.xml` contains a `<loc>` entry for every page generated by the build

### Requirement: [REQ-SO-007: Static assets copied to site]
The build SHALL copy `theme/style.css`, `theme/app.js`, and `theme/assets/minisearch.min.js` into `site/assets/` so all pages reference assets from the generated site.

#### Scenario: Assets are available in site
- **WHEN** the build completes
- **THEN** `site/assets/style.css`, `site/assets/app.js`, and `site/assets/minisearch.min.js` exist
- **AND** every generated HTML page references them via the site's `base_url`

## ADDED Requirements

### Requirement: [REQ-SO-010: Search page]
The build SHALL generate `site/search.html` from `templates/search.html.j2`, rendering the site header, a search input, facet panel containers for boards, standards, subjects, categories, concepts, and props, and a results container. Its canonical URL SHALL be the site's `base_url` plus `/search.html`, and the page SHALL reference only assets under the site's `base_url`.

#### Scenario: Search page is generated
- **WHEN** the build completes
- **THEN** `site/search.html` exists with a search input, six facet containers, and a results container
- **AND** it declares a canonical URL pointing at `/search.html` and references assets under the site's `base_url`
